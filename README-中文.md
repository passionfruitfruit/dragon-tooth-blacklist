# 龙牙附魔组合黑名单（测试版 1.1.0）

1.1.0 将全部龙牙附魔黑名单改为“完整附魔类型组合”，忽略等级。旧版黑名单自动按新规则读取；第一次成功操作后写入新版格式。无需用石英重置，也无需重新建立黑名单。

1.0.2 修复 v1.0.1 写死随机分支数量与概率、导致设备上初始化检查失败的问题。现在读取实际原版 IL，并验证 `NextBool` 的普通、double 和 float 形式，以及整数随机选择；用读到的实际阈值遍历生成器。初始化失败时会输出具体阶段与堆栈，不再只显示笼统的兼容检查失败。

1.0.1 修复兼容检查拒绝原版 `clt` 布尔比较指令的问题。升级时退出游戏，替换旧版模组文件夹；武器黑名单数据保留。本模组没有接入通用 Mod 配置菜单，不会出现在它的列表里。

适用于星露谷物语 1.6.15、SMAPI 4.5.2。支持 Steam Deck / Linux，另无前置模组。

## 安装

退出游戏，把安装包中的 `DragonToothBlacklist` 文件夹解压到游戏的 `Mods` 目录。
Steam Deck 默认目录：

`/home/deck/.local/share/Steam/steamapps/common/Stardew Valley/Mods`

游戏装在 SD 卡时，在 Steam 的游戏属性中选择“已安装文件 → 浏览”，再打开该目录下的 `Mods`。通过 SMAPI 启动游戏。

## 使用

在火山锻造台或原版便携锻造台，左边放武器，右边放材料，然后按正常锻造按钮：

- **1 个煤炭**：移除当前全部龙牙附魔，将其完整类型组合加入这把武器的黑名单，忽略所有等级。没有龙牙附魔时不能操作。
- **1 个普通石英**：清空这把武器的黑名单，保留当前全部附魔。黑名单为空时不能操作，避免白花材料。
- 以上操作不消耗火山晶石；再次使用龙牙附魔，仍按原版消耗龙牙和火山晶石。

黑名单精确匹配“完整龙牙附魔类型集合”，不比较等级，统一适用于攻击、防御、暴击、暴击伤害、速度、减重量、史莱姆采集和史莱姆克星等全部原版龙牙附魔类型。

- 禁用“攻击 +3”后，其他等级的单独攻击也被禁用；“攻击＋防御”仍可出现。
- 禁用单独“速度”后，“速度＋减重量”仍可出现。
- 禁用“速度＋减重量”后，这个组合在所有等级下均被禁用；单独“速度”仍可出现。

类型必须完整相同才被屏蔽，不会把一个单项当成所有包含该项的组合。实际允许出现的组合与等级仍由原版生成器决定。

每把武器独立保存，随存档、箱子移动和正常物品转移保留；不会影响其他武器。预览不修改原武器数据。

五彩碎片附魔、宝石强化、银河之魂进度和武器外观不在黑名单处理范围。石英只清空黑名单，煤炭只移除龙牙附魔。卸载后现有附魔照常保留，黑名单数据不再生效；重新安装后可继续使用。

## 概率与原版规则

模组在游戏中调用原版生成器，在临时武器副本上遍历全部随机分支，保存每个实际生成的“类型＋等级”结果及其原始权重。黑名单按完整类型组合过滤，所有属于该组合的等级一起被排除，然后把剩余结果的权重归一化。剩余各等级的模板与相对概率保留，不会把同一类型的不同等级折叠成一个数值，也不会拼装新组合。

原版龙牙重刷会避开上一轮出现过的附魔类型。模组在可行时保留该规则；如果该规则与黑名单冲突、剩余合法组合全部含有上一轮类型，则允许这些剩余组合，不会提前清空黑名单。煤炭已经清除当前附魔时，不存在上一轮类型限制。

只有这把武器的全部合法完整类型组合都被禁用，才自动清空黑名单。最后一次煤炭操作仍清除当前附魔，下一次龙牙附魔恢复原版合法结果池。

未来游戏更新改变随机生成逻辑时，模组会拒绝执行无法核实的黑名单操作，并在 SMAPI 日志说明原因。石英重置仍可使用。

## 验证状态与首次验收

v1.1.0 已由用户确认在 Steam Deck 正常运行，包括忽略等级、完整类型组合的黑名单规则。以下是可重复检查的操作流程。

首次建议在存档副本中验证：

1. 给有龙牙附魔的武器用煤炭：只扣 1 个煤炭，龙牙附魔消失，宝石与五彩碎片附魔保留。
2. 多次用龙牙重刷：刚禁用的完整类型组合在任何等级下均不出现；包含另一附魔的不同组合仍可出现。
3. 换另一把武器：不继承第一把的黑名单。
4. 用石英：只扣 1 个石英，当前附魔保留，黑名单清空。
5. 保存后重进游戏，并在便携锻造台重复煤炭 / 石英操作。

持有武器时，在 SMAPI 控制台运行 `dtb_check`，可查看当前组合、黑名单数量、原版合法组合数和概率总和。若操作不可用，查看日志中的 `Dragon Tooth blacklist` 错误即可定位。

对锻造流程或龙牙生成器也打补丁的模组，尚未验证兼容性。

## 从源码构建

需要 .NET 6 SDK（或安装了 net6.0 targeting pack 的新版 SDK）、游戏参考程序集和 SMAPI 4.5.2。

```sh
dotnet build DragonToothBlacklist.csproj -c Release \
  -p:GameRefs="/你的游戏或参考程序集目录" \
  -p:SmapiRefs="/你的SMAPI目录"
dotnet run --project Tests/Tests.csproj -c Release
```

测试项目使用 .NET 8 SDK。模组本身目标是 `net6.0`。生成包只需模组 DLL、manifest.json 和 i18n 文件夹，**不要包含游戏、SMAPI 或 Harmony DLL**。
